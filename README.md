# Citizen Registry REST API

![CI](https://github.com/anpapaniko-code/atlas-registry/actions/workflows/ci.yml/badge.svg)

This repository contains a RESTful service for managing a citizen registry.

The project was developed as part of the course:

**Continuous Integration / Continuous Delivery (CI/CD)**

---

## Project Structure

The project follows a **multi-module Maven architecture**.

atlas-registry  
│  
├── atlas-domain  
├── citizen-registry-service  
└── citizen-registry-client

### atlas-domain
Contains the domain model and entity classes used by the application.

### citizen-registry-service
Implements the REST API and the business logic of the citizen registry.

### citizen-registry-client
Client module used to access the REST service.

## Continuous Integration Pipeline

This project includes a **CI pipeline implemented with GitHub Actions**.

The pipeline is automatically triggered whenever a commit is pushed to the **develop** branch.

### Pipeline Steps

1. Checkout repository
2. Setup Java 17
3. Compile the project
4. Execute unit tests
5. Execute API / integration tests
6. Upload test reports as artifacts
7. Build the executable application
8. Publish an early release of the executable to GitHub Releases

This pipeline ensures that every change committed to the **develop** branch is automatically built, tested and packaged.

---

## Test Reports

Test reports generated during pipeline execution are uploaded as **GitHub Actions artifacts**.

These reports are generated by **Maven Surefire** and include detailed results for all executed unit and integration tests.

---

## Early Software Release

As part of the CI/CD pipeline, the executable JAR file of the application is automatically uploaded to the **GitHub Releases** section as an **early software release**.

This demonstrates an early stage of continuous delivery.
